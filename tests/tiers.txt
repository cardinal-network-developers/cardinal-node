# Test tiers: which test binary runs when. Read by scripts/test-tier.
#
# Every test binary of the workspace has one line here, and the script
# fails when one is missing or a line names none: a new test file cannot
# drop out of every tier.
#
#   <binary>  <tier>  <areas>  <seconds>
#
# binary   <crate dir>/lib for a library's unit tests, <crate dir>/bin/<name>
#          for a program's, <crate dir>/<name> for tests/<name>.rs.
# tier     quick    run on every edit, and in every tier
#          branch   run before a branch is merged, for its areas
#          release  run only for a release candidate (every binary runs
#                   there anyway)
# areas    comma-separated: basics, files, groups, recovery, contacts,
#          reach, calls, settings, apps, or "all" for the logic every area
#          stands on. The same words choose the drives' parts.
# seconds  about how long the binary takes alone on Saint Joseph, from the
#          last measured run; binaries side by side start longest first.
#
# A line "slow <binary> <test>" names a test that waits out real protocol
# timers. Outside the release tier it is left out, unless `--slow` is
# given (for a change to its own subject).
